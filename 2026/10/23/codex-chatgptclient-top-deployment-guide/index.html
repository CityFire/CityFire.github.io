项目概述

本文档描述了在 Ubuntu 系统中，为 chatgptclient.top 部署一套 API Key 额度查询页面的完整流程。
该服务通过 Nginx 反向代理将请求转发至本地运行的轻量级 Python 脚本，Python 脚本通过 Docker exec 进入 PostgreSQL 容器执行查询，并返回实时用量数据。前端页面支持中英双语切换、暗黑/明亮模式、按日/按月/按模型用量统计。

前置环境准备

在开始部署前，请确保服务器已安装以下组件：

  • Python 3: sudo apt install python3
  • Docker: 已安装并运行，且有 sub2api-postgres 容器。
  • Nginx: sudo apt install nginx
  • Certbot: 用于自动申请 SSL 证书 sudo apt install certbot python3-certbot-nginx
